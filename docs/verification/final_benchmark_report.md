## 1. 一句话结论与核心发现

1. **Skill 彻底消灭了所有经典表面 AI 破绽，并让生成质量达到与四大顶会真实人类作者统计无差异的出版级水准**：
   - 在三家族配对盲测（Round 3，Skill v2.1，120 份裁决）中，Unassisted Baseline 暴露的 **6 大经典表面 AI 破绽几乎归零**（尾随结果分词 `43.3% → 0.0%`、破折号堆砌 `28.3% → 0.0%`、夸张吹捧 `28.3% → 0.0%`、绝对断言 `13.3% → 0.0%`、句中 `, however,` `23.3% → 1.7%`、AI 高频词 `40.0% → 5.0%`）。
   - **学术发表质量（Quality）实现统计持平，并在 2/3 模型家族反超人类原文**：三家族汇总质量差从 Baseline 的 **`-0.40`（`p = 0.0007` 显著劣于人类，胜平率 `46.7%`）** 跃升至 Skill v2.1 的 **`-0.08`（Wilcoxon `p = 0.3958` 统计无差异！胜平率 `75.0%`）**；其中 `Claude Opus 5.5` 给 Skill v2.1 打出 **`+0.15`（95% 胜平率）**、`Gemini 4 Neon` 打出 **`+0.10`（80% 胜平率）**。在单段盲测（Standalone v2.1）中同样保持质量持平（`3.44 vs 3.56`，MWU `p = 0.5228`）。
   - **段内逻辑衔接（Cohesion）全面扭转回正**：彻底修复 Round 1/2 过矫导致的衔接下滑（`-0.52 → -0.68`），在 Round 3 跃升至 **`-0.28`（胜平率 `70.0%`）**，超越 Baseline（`-0.35`），Opus 与 Gemini 衔接胜平率达 **`85%–90%`**。
2. **计量文体学全维度收敛至“纯人类顶会标杆”分布中心**：
   - Skill v2.2 在 6 组单段测试槽位上刷新全工程最优计量纪录：中位 `|z|` 距离 **`1.29`**（低于人类 `1.59` 与 Baseline `1.73`）、均值 `|z|` **`1.70`**（人类/Baseline 均为 `2.28`）、IQR 命中率 **`14.3%`**（Baseline `8.8%`）、句长突发性 `SD = 9.41`（人类 `9.84`）、过渡副词 `6.22/100 句`、`MATTR-100 = 0.652`、`em-dash = 0.00`、AI 红牌监控词 **`0` 次命中**。
3. **直面真相：零样本单轮“要点重构”尚未突破前沿裁判的二分类图灵阈值（配对与单段 `AUC = 1.000`），且 v2.2 验证了古德哈特定律（Goodhart's Law）**：
   - 即使彻底移除配对“找茬”效应，在 18 段互斥单段盲测中，三大家族对 6 段纯人类原文的识别率为 `100%`（均值 `ai_prob = 7.9%–9.5%`），对 Baseline（`82.2%–83.3%`）与 Guided（v2.1 `76.7%` / v2.2 `80.0%`）的二分类检出率仍为 `100%`（尽管 Skill v2.1 将 Gemini 与 Opus 的判定概率显著压低 **`-10.3 pp`** 与 **`-7.0 pp`**，Opus 最低单项降至 `55% / c=2`）。
   - **两个根源**：其一是 **2017–2020 顶会真实人类稿件普遍带有未修剪的自然瑕疵与非母语微语法习惯**（悬垂修饰、大小写/数字混用、连句 `As such,` 等），干净的出版级文风天然与“带毛边初稿”区分开；其二是 **仅凭要点卡片单轮生成（而非作者本人基于真实实验直觉起草）仍会留下深层语义合成痕迹**（局部复述回声、轻微机制转述漂移与过度工整的说明句）。
   - **v2.1 → v2.2 的古德哈特反转**：v2.2 为进一步压低 `MATTR`（`0.708 → 0.652`）而过度禁止同义动词与代词省略，虽创下计量文体学历史最佳，却反而被三大前沿模型同时识破为 **“反 AI 提示词约束的机械重复”**（Gemini `anti_synonym_repetition = 6/6`，Opus `noun_repetition = 5/6`，`gpt-6.2` `paraphrase_echo = 6/6`），导致质量与衔接显著回落（配对 Wilcoxon `ΔQ = -0.39, p = 0.035`；`ΔC = -0.33, p = 0.034`）。**因此，Skill v2.1 才是感知质量与自然度的帕累托最优点；v2.2 的句长爆发力与过渡词校准必须在保留自然代词（`it`/`they`/`these`）与正常语法省略的前提下使用。**

## 2. 隔离语料与实验协议设计（零污染保证）

- **严格零接触测试集（`held_out_test`，8 篇 2016–2022 纯人类顶会论文，Phase 1 全程锁定未读）**：
  - **Split-R1（Round 1，4 篇 × 5 节 = 20 组）**：`agile_paging`（ISCA 2016）、`ceaser`（MICRO 2018）、`sparch`（HPCA 2020）、`capybara`（ASPLOS 2018）。
  - **Split-R2（Round 2 / Round 3 / Standalone，4 篇 × 5 节 = 20 组）**：`scnn`（ISCA 2017）、`simba`（MICRO 2019）、`stretch`（HPCA 2019）、`neummu`（ASPLOS 2020）。
- **防泄漏与盲审协议演进**：
  1. **等质表面归一化（`scripts/build_blind_pairs.py`）**：三组文本（Human / Baseline / Guided）均经同一函数归一化 `[REF]` 引用、引号、破折号、LaTeX 残留与空白，严格校验 `100%` 保留百分号 `%` 且长度比锁定在 `[0.92, 1.08]`。
  2. **拆包去重（Round 2 起）**：将 `human_vs_baseline` 与 `human_vs_guided` 拆分为两个完全不重叠的独立盲审包（各 20 组、严格 `10 A / 10 B`），杜绝同一人类原段在同一裁判上下文中出现两次。
  3. **物理沙箱隔离（`scripts/run_codex_blind_judges.py`）**：`gpt-6.2-astra` 每次调用均在独立空 `/tmp` 目录以 `--sandbox read-only --ephemeral` + 严格 OpenAI JSON Schema 运行，对工作区路径、组别名称与标准答案物理不可见。
  4. **单段互斥测试（Standalone v2.1 / v2.2）**：从 Split-R2 的 `4×5=20` 网格中拉丁方抽样 18 个完全互斥的 `(paper, section)` 单元格（`6 Human + 6 Baseline + 6 Guided`，每组均覆盖全部 4 顶会与全部 5 章节），消除配对“逐句找 ESL 语法瑕疵”的作弊红利。

### 3.4 真实人类读者双盲实测补充验证（2 位体系结构读者 × 6 题 A/B = 12 份盲判）

在 6 题无剧透双盲测试集（`Q1–Q6`，覆盖 4 顶会 × 5 章节，5 篇冻结 v2.2 + 1 篇 v2.1）上采集了 **2 位真实人类读者**的独立盲判与定性理由，呈现出与前沿大模型截然不同的关键现象：
- **真人 AI 辨别率落回随机猜测水平（`50.0%`）**：两位测试者分别命中 **`3/6`（`50.0%`，均值把握度 `3.33`）** 与 **`3/6`（`50.0%`，均值把握度 `3.00`）**，合计 **`6/12 = 50.0%`**（二项检验 `p = 1.00`）。其中 `Q4`（SCNN Intro）与 `Q5`（NeuMMU Motivation）两位测试者 **`0/2` 全错**——人类读者并未将 2017–2020 原稿的 ESL 语法瑕疵当作防伪信号，反而将原稿中密集的破折号 `—` 与 `(i.e., ...)` 括号说明判成了 AI。
- **可读性偏好分化**：测试者 1 在 **`4/6` 题中直接判 Agent 可读性更高 + `1` 题持平（胜平率 `83.3%`）**；测试者 2 对“作者第一人称叙事感”高度敏感，在 `6/6` 题中均更偏爱人类原段（即便在 `Q4/Q5/Q6` 误把人类段当成了 AI）。
- **人类反馈直接催生 `v1.0.2` 四项精准修补**：(1) 纠正设计选型与实验段“零 `We` 客观说明书腔”，保留自然第一人称 `We` 视角（`We chose X because`, `We first compare`, `we expect`）；(2) 禁止为凑句长突发性硬插孤立短句与悬空二元指代 `both`；(3) 在 `We propose <SysName>` 前保留扎根前文观察的具象因果桥（`To exploit this slack, we propose...`）；(4) 将隐喻动词 `absorb`（`absorb the slowdown`）纳入 Tier-2 替换表（改用 `hide / tolerate / offset / mask`）。

## 5. 坦诚的科学诊断：Skill 真正解决了什么，以及单轮全自动生成的边界

### 5.1 本工程已被严格证实的四大硬价值
1. **彻底根除 LLM 表面“AI 味”与高危学术修辞缺陷**：在 468 份跨家族盲审中，`participle_tail`、`em_dash_overuse`、`cheerleading_hype`、`unsupported_certainty`、`ai_lexicon` 等顶级审稿人最反感的 AI 病灶全部被压至 `0%–5%`。
2. **学术质量从显著落后跃升至出版级持平/反超**：三家族配对盲测中，Unassisted Baseline 质量显著逊于人类（`-0.40`, `p=0.0007`），而 Skill v2.1 将质量提升至 **`-0.08`（`p=0.3958` 统计无差异，胜平率 `75%`）**，且在 `Claude Opus 5.5`（`+0.15`）与 `Gemini 4 Neon`（`+0.10`）上直接超越已发表顶会原文。
3. **揭示并定位了“反 AI 过矫（Class-C Over-Correction）”的三次演化陷阱**：
   - `v1.0` 陷阱：禁过渡词 + 放任破折号 → 零过渡断奏 + 破折号爆发；
   - `v2.0` 陷阱：无上限强调 Given-New 衔接 → 机械尾头复读（`GN5 = 61.3%`, `paraphrase_echo = 80%`）；
   - `v2.2` 陷阱：过度追低 `MATTR`（`0.652`）禁用同义动词与自然代词 → 机械名词重复（`anti_synonym_repetition = 6/6`），证实**不可用单一计量阈值替代语言自然度**。
4. **验证了人类原文与 AI 文本之间的“不对称瑕疵鸿沟”**：所有 6 段 2017–2020 纯人类原文在单段盲测中都以 `3%–15%` 极低 AI 概率被全票认出，因为真实顶会论文普遍保留着微小的语法粗糙、拼写/数字格式不统一（如 `ResNet-50`/`ResNet50`、`0.11 pJ/Op`/`0.16 pJ/op`）和极具个人印记的措辞。**工程目标绝不是让 Skill 故意制造病句或错别字去骗过检测器**，而是输出干净、诚实、逻辑严密的顶会工程散文。

### 5.2 为何零样本单轮“要点→成文”仍无法突破前沿单段检测（`AUC = 1.000`）
即便剔除人类瑕疵因素，三大家族裁判仍从 Skill 段落内部独立识别出两类源于**“脱离完整研究心智模型的要点卡片重构”**的深层信号：
1. **局部机制转述漂移与冗余解释**：模型只看到提炼后的要点条目，偶尔会在转述因果链时丢失隐含微架构前提（例如将 IOMMU Walker 拥塞误转述为给本地 TLB “留出恢复时间”、将硬件原型误称为 “first study”、或用两句话重复清点同一组寄存器）。
2. **反同义词规则与自然省略的张力**：人类作者在写熟知系统时自然交替使用原词、代词（`it`/`they`/`these`）和语法省略；当模型被强规则约束“既不能换同义词、又不能留裸代词、又要控句长”时，极易退化为“无代词重复名词块”或“过工整陈述句流”。

### 5.3 面向真实科研写作的最佳落地建议
- **推荐工作流（Human-in-the-Loop + Skill 结构/去 AI 纪律）**：
  1. **核心技术草稿由作者本人（或带完整实验上下文的交互式共写）先写清因果机制与真实边界**，避免“把零散要点扔给模型一次性憋出全段”；
  2. **调用本插件 Skill（`skills/arch-paper-writing/`）执行两遍式手术修订**：
     - **架构层**：对齐四大顶会篇幅预算（`01`）、五步摘要与黄金前两页（`02`）、六层设计抽象控制（`03`）、负结果诚实表达与图表图注规范（`07`）；
     - **文本层**：清除所有 Tier-1/2 AI 词、尾随结果分词、破折号堆砌、夸大断言与空心壳名词（`05`/`06`/`08`），**同时严格保留自然代词（`it`/`they`）与合乎语法的省略，绝不为压低 `MATTR` 而强行删掉代词或复读全称名词**。
  3. **部署方式**：请参考 [README.md](../../README.md) 将本插件安装至 `~/.gemini/config/plugins/arch-paper-writing/` 或项目 `.agents/plugins/` 目录。
